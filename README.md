# CryoBoost

CryoBoost is a comprehensive cryo-electron microscopy (cryo-EM) data processing system designed to orchestrate complex tomographic workflows from raw data acquisition to final particle extraction and analysis. The system provides both graphical and command-line interfaces for managing multi-step processing pipelines that integrate external software packages including RELION, Warp, PyTOM, and IMOD.
